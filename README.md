# DanceAcademy – Dance Academy Management System

**Developed by Karthika Mohanamuthu**

DanceAcademy is an ASP.NET Core MVC web application designed to manage a dance academy's activities, student enquiries and enrolments.

## Features

- Responsive homepage and academy information pages
- Dance styles, classes and fee details
- Parent and student enquiry submission
- ASP.NET Core Identity-based Admin Login
- Admin enquiry management
- Enrolment workflow
- Automatic student record creation after enrolment
- Student management dashboard

## Technology Stack

- ASP.NET Core MVC (.NET 9)
- C#
- Entity Framework Core
- Microsoft SQL Server
- ASP.NET Core Identity
- HTML, CSS, Bootstrap and JavaScript

## Project Structure

- Controllers – Application logic
- Models – Application data models
- Views – Razor UI pages
- Migrations – Database schema changes
- wwwroot – Static assets such as CSS, JavaScript and images

## Security

- Admin authentication and role-based authorization
- Credentials managed through ASP.NET Core User Secrets
- Sensitive configuration and local database files excluded from source control
